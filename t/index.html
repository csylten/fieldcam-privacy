FieldCam Team Template

Someone shared a FieldCam Team Template with you: camera, overlay and tag settings, so the whole crew works the same way.

1. Get FieldCam

Android: coming to Google Play

2. Scan the code again, inside FieldCam

Open FieldCam and go to Settings → Team Template → Import Team Template. Scan the same QR code. FieldCam shows what is included before you use it.

Already have FieldCam? Scan the code from inside the app, not with the phone's own camera. That way the settings go straight into FieldCam.

Privacy

The settings are in the part of the link after the #. Your browser never sends that part to this website. This page only shows the template name on your phone. It sends nothing and stores nothing. See the privacy policy.
